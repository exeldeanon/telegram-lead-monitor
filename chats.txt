# Список чатов для мониторинга
# Поддерживаются форматы:
#   - Числовые ID (например: -1001234567890)
#   - Username без @ (например: my_chat_username)
#   - Ссылки-приглашения (не рекомендуется, лучше использовать ID/username)
# По одному значению на строку. Строки, начинающиеся с #, игнорируются.

# Примеры:
# -1001234567890
# business_chat_ru
# leadgen_marketplace
